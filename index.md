# Welcome to the Volume Control iCUE Widget Docs

This widget allows you to control the volume of specific apps by with the dial on corsair keyboards that support widgets (Vanguard 96/PRO)

### Quick Start
1. Download and install the backend latest release.
2. Install the widget to your iCUE profile.
3. Configure the apps you wish to control the volume off, and the visual customisation of the widget.
